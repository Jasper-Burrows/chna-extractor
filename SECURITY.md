# Security policy

Please report suspected vulnerabilities privately through GitHub's security-advisory feature. Do not
open a public issue containing secrets, private reports, or exploit details.

Supported security fixes target the latest `1.x` release. This portfolio project is not a hosted
service and has no bug-bounty program.

Never submit an internship credential or production report when reproducing a problem. Use the
bundled synthetic fixture. Any credential found in an older local project should be considered
compromised and rotated; this repository neither needs nor reads it.
